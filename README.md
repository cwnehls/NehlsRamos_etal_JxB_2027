# NehlsRamos_etal_JxB_2027
Supplementary data and code for the publication Nehls-Ramos et al. 2027

Code and Dataset for "Redox regulation of 2-carboxy-D-arabinitol 1-phosphate phosphatase in Fabaceae is associated with high Rubisco dark inhibition"

Authors: Connor Nehls-Ramos, Elizabete Carmo-Silva, Douglas J. Orr

The R code supplied in this folder is for the analyses and production of plots for the dataset used in the paper stated above. All code included is intended to be run individually for each file, and run at once within each file-- unless specified otherwise in the description included in the file. The dataset and code includes all necessary information to recreate the figures in the paper.

Code file names are presented in connection to the figure or section of paper relevant for said code. The "S" signifies Supplemental

Contained are the results from D-I-Tasser analysis performed as described in materials and methods

.pdb files obtained form the Protein Data Bank. The .gz implies a compressed version of the file.
